# Release notes — v2.1.0

## Исправлено

1. Короткие и формальные AI-ответы больше не заменяют полноценный финансовый отчет.
2. Детерминированный анализ стал обязательным минимальным уровнем качества.
3. Расширено распознавание официальных строк РСБУ и механические выводы из компонентов.
4. Известный 78-страничный отчет ЛУКОЙЛ определяется после пересохранения PDF.
5. Добавлено шесть новых финансовых показателей и коэффициентов.
6. В AI передаются строки с проверенными источниками `ras_coordinate_ocr`, а не только данные с уверенностью выше 90%.
7. Удален автоматический запуск браузера из macOS-скрипта.

## Совместимость

- Python 3.11–3.13
- macOS Intel и Apple Silicon
- Docker / Render / Railway
- OpenAI-compatible API
