# FinSight AI 3.4.1 — отчет о проверке

Дата: 2026-08-11

- 45 тестов пройдено, 1 медленный тест полного 131-страничного PDF пропущен по умолчанию, 0 ошибок.
- Автоматические тесты проверяют API, PDF/XLSX/DOCX parsing, OCR, canonical model, provenance, validation, коэффициенты, тренды, AI payload и три профессиональных экспорта.
- Добавлены регрессии на датированные годовые колонки, произвольную организацию и структуру XLSX РСБУ, официальный код строки при измененном названии, плохой скрытый OCR, позднюю страницу формы, баланс с одним искаженным итогом и неразрушающую валидацию.
- Полный проход 78-страничного скана РСБУ без текстового слоя: OCR 78/78 страниц, 0 ошибок, 33 валидированные финансовые строки, 24 рассчитанных коэффициента, 6 из 6 балансовых проверок пройдены, validation `passed`.
- Полный проход 131-страничного текстового годового отчета: медленный smoke test пройден.
- Публичная отчетность ПАО «Сбербанк России»: распознаны формы Банка России 0409806 и 0409807, 21 валидированный показатель и 10 банковских коэффициентов; балансовое равенство за оба периода прошло проверку.
- Добавлен регрессионный тест банковского профиля: распознавание выбирается по коду формы и не содержит привязки к названию банка.
- JavaScript интерфейса проверяется через `node --check`.
- Excel открывается `openpyxl`, Word — `python-docx`, PDF — PyMuPDF; дополнительно выполняется визуальный рендер Word/PDF.
- Визуальная проверка экспорта: Word — 3 страницы, PDF — 5 страниц, Excel — 6 листов; кириллица, переносы и повторяющиеся заголовки таблиц отображаются корректно.
- Docker содержит Tesseract `rus+eng`, кириллические шрифты, Word/PDF export dependencies и запуск на `${PORT}`.
- Демо и пользовательские файлы используют один универсальный конвейер; company-specific financial values в рабочем коде отсутствуют.

Команды повторной проверки:

```bash
PYTHONPATH=backend python3 -m pytest -q
node --check frontend/dist/app.js
```
