# Визуальная адаптация под фирменный стиль Финансового университета

Версия интерфейса: **1.3.0 University Brand Edition**.

Визуальная система frontend приведена к параметрам предоставленного брендбука:

- основной фирменный цвет: `#256569`;
- дополнительные цвета: `#0098AF`, `#006B80`;
- цвета фирменного знака: `#355CA8` и `#D80F16`;
- основной web-шрифт: `Open Sans` с системными fallback-шрифтами;
- для крупных заголовков используется Book Antiqua / Palatino / Georgia как безопасная web-цепочка;
- официальный логотип используется без изменения пропорций, цветов и взаимного расположения элементов;
- вокруг логотипа сохраняется свободное поле за счет отдельного белого контейнера;
- декоративная модульная сетка повторяет мотив фирменных материалов;
- интерфейс содержит пояснение, что FinSight AI является учебным ВКР-стартапом, а не официальным сервисом университета.

Файлы визуальной темы находятся в `frontend/dist/`, изображения — в `frontend/dist/assets/`.
