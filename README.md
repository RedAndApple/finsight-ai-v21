# FinSight AI — Financial University Brand Edition v3.4.1

Учебный ВКР-стартап для автоматического анализа отчетности РСБУ и МСФО. Приложение читает текстовые PDF, сканы, изображения, DOCX, XLSX/XLS и CSV, приводит данные к единой финансовой модели, проверяет их, рассчитывает коэффициенты и формирует профессиональное AI-заключение.

## Что изменено в v3.4.1

- Добавлен универсальный профиль публичной отчетности кредитных организаций по формам Банка России 0409806 и 0409807. Выбор выполняется по коду формы, без привязки к названию банка.
- Для банков рассчитываются ROA, ROE, Equity/Assets, Loan-to-Deposit, Cost-to-Income, Credit Loss Charge/Loans, Net Interest Income/Assets и динамика процентных, комиссионных доходов и чистой прибыли.
- Промышленные коэффициенты Current Ratio, EBITDA Margin и Debt/Equity не применяются к банкам; интерфейс и AI используют отдельную банковскую методологию.
- Баланс банка проверяется равенством «Активы = Обязательства + Собственные средства», а каждая строка сохраняет ссылку на форму, номер строки и страницу.

## Базовые возможности v3.4

- Убран позиционный лимит, из-за которого формы после первых 18 страниц оставались без OCR: при `OCR_MAX_PAGES=0` проверяется весь документ.
- Качество скрытого текстового слоя оценивается по словам и шуму, а не только по числу символов. Плохой встроенный OCR заменяется новым распознаванием.
- Для сложной страницы выполняются независимые OCR-проходы с разной сегментацией; финансовая форма повторно читается в повышенном разрешении.
- Если локальный parser не нашел полный баланс, ОФР и ОДДС, мультимодальная модель ищет страницы форм на контактных листах всего PDF и затем транскрибирует выбранные страницы.
- РСБУ извлекается по официальным кодам строк 1100–1700, 2100–2500 и 4100–4500, включая таблицы PDF, Excel и Word. Название организации не влияет на алгоритм.
- Основные формы МСФО извлекаются отдельно от примечаний по заголовкам и координатам годовых колонок.
- Заголовки вида `31.12.2025` и `За год, закончившийся 2025` корректно привязываются к периоду; колонки `Изменение 2025/2024` не принимаются за исходный год.
- Балансовые равенства не стирают всю модель из-за одной ошибочной цифры. Если два независимых итога совпадают, единичное OCR-отклонение восстанавливается с сохранением исходного значения и предупреждения.
- DOCX с вложенными сканами теперь проходит OCR, а электронные таблицы сохраняют лист и номер исходной строки.
- AI получает только нормализованные показатели, рассчитанные кодом коэффициенты и проверенные раскрытия. Ответ проверяется на структуру, новые числа, повторы и технический JSON.
- В конце каждого результата доступны оформленные Excel, Word и PDF, а также технические CSV и JSON.

## Быстрый запуск на macOS

1. Распакуйте архив.
2. Откройте Terminal и перейдите в папку проекта.
3. Выполните:

```bash
bash start_mac.command
```

4. Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).
5. Для остановки нажмите `Ctrl+C` в Terminal.

Скрипт сам создаст `.venv`, установит Python-зависимости и скопирует `.env.example` в `.env`. Для распознавания сканов на macOS установите Tesseract:

```bash
brew install tesseract tesseract-lang
tesseract --list-langs | grep -E 'rus|eng'
```

## Настройка AI

Откройте `.env` и заполните OpenAI-совместимый API:

```env
AI_BASE_URL=https://your-api.example.com/v1
AI_API_KEY=your-secret-key
AI_MODEL=your-text-model
VISION_MODEL=your-multimodal-model
AUTO_AI=true
ENABLE_VISION_RECOVERY=true
VISION_MAX_PAGES=12
VISION_LOCATOR_MAX_PAGES=180
OCR_MAX_PAGES=0
```

`VISION_MODEL` должна принимать изображения. Ее задача — найти и точно переписать строки основных форм; арифметику по-прежнему выполняет код приложения. Если указать одну мультимодальную модель в `AI_MODEL`, `VISION_MODEL` можно оставить пустой.

## Docker

```bash
cp .env.example .env
# заполните AI_API_KEY и модели
docker compose up --build
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Docker-образ уже содержит Tesseract `rus+eng`, шрифты для кириллицы и библиотеки экспорта.

## Render

В репозитории есть `render.yaml`. Создайте Blueprint, добавьте секрет `AI_API_KEY` и при необходимости измените `AI_MODEL`/`VISION_MODEL`. На бесплатном тарифе локальная папка данных является временной: после перезапуска сервиса история загрузок может очищаться. Для постоянной истории подключите Render Disk или внешнее объектное хранилище.

## Проверка

```bash
PYTHONPATH=backend python3 -m pytest -q
node --check frontend/dist/app.js
```

## Принцип точности

FinSight не содержит заранее записанных чисел ЛУКОЙЛа или других организаций: демонстрационный PDF проходит тот же `process_document`, что и пользовательская загрузка. Каждое значение хранит источник до страницы/листа, строки и кода; коэффициенты рассчитываются детерминированно.

Абсолютно гарантировать чтение любого физически поврежденного, обрезанного или неразличимого скана невозможно. Поэтому система использует несколько независимых способов извлечения и повторное визуальное чтение, но не придумывает отсутствующие цифры. Результат не заменяет аудит и не является инвестиционной рекомендацией.
