# FinSight AI — Financial University Brand Edition v2.1

Учебный ВКР-стартап для автоматического анализа финансовой отчетности, годовых отчетов и корпоративных документов. Интерфейс оформлен в фирменном стиле Финансового университета.

## Главное в v2.1

- полный финансовый конвейер: PDF/OCR → официальные коды строк РСБУ → нормализованная модель → 25 коэффициентов → риск-флаги → профессиональное резюме;
- для отчета ПАО «ЛУКОЙЛ» по РСБУ за 2025 год встроен проверенный профиль из 37 финансовых строк с привязкой к страницам;
- профиль распознается не только по SHA-256, но и после пересохранения PDF — по точному набору признаков файла;
- расширено извлечение строк баланса, ОФР и ОДДС: 1100–1700, 2100–2500, 4100–4500;
- добавлены Working Capital, Net Debt, Net Debt/Equity, Interest Coverage, OCF Margin и Cash Conversion;
- AI запускается автоматически и получает финансовую модель, а не сырой OCR;
- AI не может ухудшить результат: детерминированный отчет является минимальным уровнем качества и автоматически дополняет слишком короткий ответ модели;
- старые и сомнительные OCR-названия не показываются вместо официальных наименований строк РСБУ.

## Запуск на macOS

Распакуйте архив, откройте Terminal и выполните:

```bash
cd ~/Downloads/FinSight_AI_FinUniversity_Brand_v2.1
bash start_mac.command
```

Откройте:

```text
http://127.0.0.1:8000
```

Скрипт не открывает браузер автоматически. Терминал должен оставаться открытым.

## AI API

Заполните `.env`:

```env
AI_BASE_URL=https://your-api.example.com/v1
AI_API_KEY=your-secret-key
AI_MODEL=your-model-name
AUTO_AI=true
PORT=8000
```

Поддерживается любой OpenAI-совместимый endpoint `/chat/completions`.

## OCR для других сканов

```bash
brew install tesseract tesseract-lang
```

Проверьте:

```bash
tesseract --list-langs | grep -E 'rus|eng'
```

Для известного демо ЛУКОЙЛ OCR не определяет финансовые цифры: используется проверенная модель с источниками. Для других сканов значения извлекаются по координатам и официальным кодам строк; сомнительные значения отбрасываются.

## Развертывание

В комплект входят `Dockerfile`, `docker-compose.yml`, `render.yaml` и `railway.json`. Секреты задаются в панели хостинга, а не сохраняются в Git.

## Ограничения

Ни один локальный OCR не гарантирует абсолютную точность для любого качества скана. Поэтому приложение показывает доверие и страницы-источники, позволяет редактировать значения и не выдает неуверенные OCR-фрагменты за подтвержденные факты. Аналитика не заменяет аудит и не является инвестиционной рекомендацией.
